# Employee Management & Leave Tracking System

A web-based application designed to simplify employee management and leave tracking using a modern React frontend and Spring Boot backend.

## 🚀 Technologies Used

- **Frontend:** React.js, Vite, JavaScript, CSS
- **HTTP Client:** Axios
- **Routing:** React Router
- **Backend:** Java, Spring Boot
- **Database:** MySQL
- **Authentication:** Spring Security and JWT

## ✨ Features

- User-friendly and responsive interface
- Employee management
- Leave request and tracking
- Login and authentication
- Frontend integration with REST APIs

## 📁 Project Setup

### Prerequisites
- Node.js and npm
- Java and Maven
- MySQL

### Run the Frontend

```bash
git clone https://github.com/mohamed-nafil/employee-management-frontend.git
cd employee-management-frontend
npm install
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

```bash
npm run build
```
